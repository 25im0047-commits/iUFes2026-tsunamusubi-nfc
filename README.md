# iUFes2026 システムプロトタイプ

iU FesのNFCスタンプラリーを動作確認するTanStack Startプロトタイプです。本リポジトリはiU Fesの周遊企画を扱います。他の企画・公式サイトはそれぞれ別リポジトリで管理します。

会場図、出店名、おばけの文面、設置場所、良いおばけ5体の構成は仮データです。画面は本番デザインではありません。アンケート・回答集計・受付クイズは未実装で、本番運用できる状態ではありません。

## 実装フロー

1. パンフレットのQRからWebページへアクセス
2. おばけMapを表示
3. NFCタグに書かれたURL（例：`https://example.com/?id=good-01`）をスマートフォンの標準機能で開く
4. URLの`id`でおばけを特定し、処理後に`id`だけを削除（他のクエリとハッシュは保持）
5. 良いおばけとの会話終了でスタンプを`localStorage`へ保存
6. 良いおばけをすべて集めると、悪いおばけ2体をMapへ表示
7. 悪いおばけとの会話後、受付でクイズへ進む案内を表示
8. 取得済みスタンプのカードをタッチすると、そのおばけとの会話画面を再表示する

悪いおばけは現在、URLを開いた時点で訪問済みになります。良いおばけ未達成でも直接URLから開けるため、Map上の非表示だけでは解放制御が完了していません。アンケート送信完了とは区別してください。受付案内も仮実装です。

進捗は同じブラウザー・同じオリジンの`localStorage`へ保存します。読み込み時に重複・未知・種類違いのIDを除去し、全対象IDの取得を達成条件とします。保存に失敗した場合は警告と再試行ボタンを表示し、画面内の進捗を保持します。端末間同期・不正防止・回答の永続保存は提供していません。

## 本番画像への差し替え

おばけ画像はデータの `imageSrc` を指定するだけで差し替えられる構造です。例えば `public/ghosts/good-01.webp` を追加し、`src/lib/rally.ts` の対象データに `imageSrc: '/ghosts/good-01.webp'` を設定してください。未設定時は仮のおばけプレースホルダーが表示されます。

## 起動

```bash
npm ci
npm run dev
```

Node.js 22.12.0以上を使用してください。起動先は`http://localhost:3001`です。例：`http://localhost:3001/?id=good-01`。実機のNFC確認には、端末からアクセスできるHTTPS環境を用意します。

```bash
npm run typecheck
npm test
npm run build
```

PRとmainへのpushでは、GitHub ActionsでWindows/Linux、Node.js 22.12.0/24のチェックを実行します。各PRのChecksで結果を確認してください。
