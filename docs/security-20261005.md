# 2026-10-05 TanStack Start セキュリティ更新

TanStack公式の [CVE-2026-102989 / GHSA-qx66-fv34-fjm8](https://github.com/TanStack/router/security/advisories/GHSA-qx66-fv34-fjm8)（9月30日公開、Critical）に、変更前の依存関係が該当していた。server functionのリクエスト由来の値が内部状態・レスポンスとして扱われることで、反射型XSSにつながる問題。

| パッケージ | 更新前 | 更新後 |
| --- | --- | --- |
| `@tanstack/react-start` | 1.168.49 | 1.168.60 |
| `@tanstack/start-server-core` | 1.169.31 | 1.169.39 |

`react-start` を公式の修正版1.168.60へ固定し、lockを更新した。この版は修正済み `start-server-core@1.169.39` を固定依存に持つ。Startが必要とするrouterを1.170.41へ揃え、lock・インストール済みツリーともに対象パッケージの旧版・重複がないことを確認した。React/React DOM、Vite、Nitro、TypeScriptの版は変えていない。

公式修正は公開入力フィールドへの限定と、サーバー境界でのレスポンス検証を行う。監査の無効化、例外登録、WAFによる代替は行っていない。既存アプリは独自server function/RSCを使っていないが、それだけを根拠に影響がないとは判定しない。

## 検証

- `npm ci` が成功し、更新したlockを再現できる。
- `npm audit --json --ignore-scripts` は検出0件。更新前にも0件だったため、この結果単独で上記脆弱性がないとは判定できない。公式advisoryの修正版とlock・実依存の版を別途照合した。
- 型チェック、単体38件、Vercel用ビルド、生成されたVercel配信ハンドラのテスト3件が成功。
- 既存の `use client` バンドル警告は更新前にもあった。新しい重大なビルド警告は確認されていない。
- 本番SSR配信でのChromium/WebKit全54件が成功。確定画像、11体取得、晴雨切替、旧進捗の移行・タブ同期・任意アンケートを確認。実回答の外部送信なし。
- 独立レビューで、旧版の残存・重複、Node/peer互換性、新しい重大警告、既存機能への重大な影響は見つからなかった。

## ビルド失敗の調査範囲

調査時点のmain `726aed5a825cb65feb9d958064928ce80aff17ae` はGitHub CIの全5ジョブが成功していた。一方、[Vercel deployment](https://vercel.com/shotakobayashis-projects/i-u-fes2026-tsunamusubi-nfc/EJCsM4pNh4samaSM3sVULigDU2kr) は失敗状態だった。正規連携で対象チームのログを取得しようとしたが、チーム権限不足の403 Forbiddenで読めなかった。失敗ログに示されたパッケージ名/CVEとの一致は未確認であり、今回の公式告知に該当する依存関係の修正と、Vercel上のビルド失敗の解消を同一視しない。

既存PRのVercel statusには、Git作者のプロジェクトアクセス不足という別の失敗理由も記録されている。手動デプロイやVercel認証・権限の変更は行っていない。
