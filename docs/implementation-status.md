## 今回の検証

2026-09-27の設計レビューを受け、保存形式v3への移行・回答の固定ID化・未対応版の保護・別タブ同期を追加しました。実装後のコードレビューでは、進捗が変わらない画面復帰で表示画面を維持すること、別タブで全取得となった際に取得カードの文言と遷移先を揃えることも修正しました。

文言変更、旧データ移行、保存失敗、未対応形式、タブ間同期・画面復帰の回帰テストを追加しています。移行時の旧版タブの再読み込みと保存キーの扱いは[参加者フロー](participant-flow.md#保存と完了の関係)を参照してください。

最終確認はWindows / Node 24.20.0で、型チェック・単体29件・本番ブラウザー42件（21件 × Chromium/WebKit）・Node/Vercel向けビルド・Vercel配信テスト3件がすべて成功しました。実機NFC、実機Safari、会場通信、Vercel公開先での動作確認は含みません。

同日のモバイル検証では7サイズを確認し、フォントによる件数の折り返し、おばけの見切れ、WebKitのタップ後のフォーカス復帰を修正しました。詳細は[モバイル表示・軽量化の検証](mobile-verification.md)を参照してください。

### 2026-09-26の検証履歴

追加レビューで、native dialogの位置指定と会話終了時のフォーカス復帰を修正しました。[変更履歴](../CHANGELOG.md)を参照してください。Playwrightのブラウザーテスト8件を追加し、スクロール後の中央配置、320px幅・横画面を含む4サイズ、リサイズ、キーボード操作、全取得フロー、保存失敗からの再試行を検証します。

ローカルのWindows / Node 24.20.0で単体テスト22件・型チェック・本番ビルドが成功。ブラウザーでは以下を確認しました。

- タイトル→説明→Map、会話を閉じただけでは未取得、良いおばけ5体の終了→出現演出。
- 解放前の悪いおばけURLは会話を開かず案内。URLの他のクエリ・ハッシュは保持。
- ヴァンパイア→メデューサの順で進行し、回答保存失敗→再試行で入力内容を保持。
- メデューサの複数選択と0点の回答、全取得→受付提示、再読み込み後の完了状態。
- 390px幅の画面とフォームで横方向のはみ出しなし。確認中のブラウザー例外・Viteエラー画面なし。

両方の訪問順、全問未回答、範囲外スコア、文字数上限、旧データ移行、誤った全取得、重複完了、保存障害は自動テストで検証します。ビルドと各CI環境の実行結果はPRのChecksを参照してください。NFC実機、iOS/Safari、会場通信は未検証です。

## 本番に向けた残作業

1. **運営への回答送信・自動集計**：現在は端末内保存のみ。中央DB・送信API・集計画面は未実装。フォームにも運営に送信しない旨を表示しています。集計先・権限・保持期間を設定し、匿名の重複防止・送信再試行・サーバー側検証を実装する必要があります。
2. **会場・コンテンツ**：最終の良いおばけIDと体数、会話・画像、実会場図、座標を反映。悪いおばけは屋内として表示しますが、具体的な場所は未確定です。音声と表情素材は未実装です。
3. **公開と実機確認**：HTTPS公開先、NFCタグ、iOS/Android、通信が弱い場合、雨天配置、当日の受付運用を確認。
4. **受付クイズは将来のみ**：[拡張設計](participant-flow.md#将来の受付クイズ設計未実装今回は無効)を残し、今回の参加条件には含めません。

localStorageは手動改変・端末間同期・同時書き込みの完全な保証を提供しません。このプロトタイプの完了表示は認証済みの景品受領証ではありません。
