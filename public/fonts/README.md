# Design reference fonts

These unchanged WOFF2 subsets were extracted from the supplied
`iUFes2026 おばけMap デザイン案.html`. They are served locally, without
requests to Google Fonts or another font CDN. Characters not included in
the supplied subsets use the system font fallback.

- Dela Gothic One: https://github.com/google/fonts/tree/main/ofl/delagothicone
- Zen Maru Gothic: https://github.com/google/fonts/tree/main/ofl/zenmarugothic

Copyright notices and the SIL Open Font License 1.1 are in `OFL.txt`.
